# Skills

Every skill in this repository, one folder each. This folder is the only copy anyone edits; `scripts/deploy_skills.py` writes the copies agent tools read. Create and change skills through `meta-skills-govern`; the validator checks that every skill has a row here.

| Skill | What it does |
|---|---|
| `meta-skills-govern` | Creates, updates, reviews and retires skills, and finds which skill fits a task |
| `notes-actions-extract` | Lists the action items in a meeting notes file as a checklist (the worked example) |
