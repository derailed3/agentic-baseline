# Extract action items

1. Confirm the path of the notes file with the person.
2. Run `python <skill-folder>/scripts/extract_actions.py <notes-file>`, where `<skill-folder>` is this skill's folder.
3. Show the checklist exactly as printed. Do not add items the script did not find.
4. If it prints "No action items found.", say so and ask how items are marked.
